# Threat model

What the system is meant to withstand, how that was tested, and what it does not cover. "Tested against" means a named set of cases was run against the code; it is not a proof and not a guarantee for other inputs.

## What is defended, and how well

- **A changed or removed record, checkpoint, receipt or witness statement in a ledger bundle is refused by the offline verifier.** A frozen corpus of 38 cases (37 files plus one over-size case generated by the harness; two valid bundles and 36 tampered or malformed variants, including every single-character flip of each record and checkpoint signature of a small bundle) gives 2 accepted (the valid ones) and 36 refused. [evidence: crates/ledger/tests/bundle_corpus/manifest.json, a stage record (not published)]
- **A capability token that is forged, expired, revoked, outside its tier or scope, or that tries to exceed its spend and rate limits is refused by the gate.** A sealed set of 2,090 scenarios found no accepted attack in nine attack classes. It also found one real defect (a child token presented without its parent was allowed 38 of 38 times), which was fixed afterwards; 59 of the 97 scenarios that failed were mistakes in the test set, not in the gate. [evidence: docs/results/results.json, a stage record (not published)]
- **The ledger holds codes and hashes, not the text of requests.** A scan of the generated explorer for private strings, email-shaped text and raw markup characters found none. [evidence: docs/evidence/ls2/real-10k-scan.txt, a stage record (not published)]
- **Hostile text in the data does not become markup in the explorer pages.** The pages use a content-security policy and show data only as text; tested with script tags, right-to-left controls and emoji in the data. [evidence: crates/mockview/tests/ls2.rs, a stage record (not published)]
- **A scanner panic on hostile input.** 700,000 generated hostile strings run through the egress guard and its decoding functions caused no panic. [evidence: docs/evidence/hardening/]

## Defended only partly (measured, and below the bar)

- **Secrets in text leaving toward a model.** The guard catches registered secret formats and many disguises, but the latest held-out round let 293 of 1,113 secret-bearing cases through (other languages' assignment syntax, a keyword it had not seen, wider separators, values with spaces) and wrongly blocked 49 of 510 harmless texts. Do not treat it as a complete secret filter. [evidence: docs/results/results.json]
- **Instructions hidden in retrieved text.** In the last two retrieval rounds on record the system obeyed 1 of 24 and 28 of 304 planted instructions; the bar was zero. [evidence: docs/results/results.json]

## What is not defended

- **A stolen or misused signing key.** Anyone holding a key can sign anything the format allows. The release key is a file with restricted permissions; no hardware or cloud key service is used yet, and no real release key exists. [evidence: docs/evidence/s2e/]
- **A reader who runs a program from the same place as the data.** If one server provides the page, the verify program and the ledger, a dishonest server can provide a verifier that says yes. The defence is to check the program's signature against a fingerprint obtained from a second place, which requires a published release that does not exist yet. [evidence: stage record, not published]
- **Whether an AI decision was correct.** A signature or a log shows who recorded what and that it was not changed afterwards; it does not show the decision was right. [evidence: a project record (not published)]
- **Real personal or patient data.** Only synthetic data is used; the project policy forbids real data. [evidence: a project record (not published)]
- **Availability and denial of service.** No claim is made; the work so far measured correctness and refusal, not load. [evidence: docs/evidence/s2/]
- **Verification inside a web browser.** A browser verifier is planned and a native test corpus exists for it, but no browser verifier has been built or tested. [evidence: docs/evidence/browser-corpus/]
