# results.json (schema `results-1`)
Generated by `tools/results/make_results.py` from `results-spec.json`; every number is checked against a report file first (131 checks), and the file is written only if all pass.
- top level: `schema`, `label` (wording: tested against; evidence mapped to the control, not a security claim), `summary` {rows, bars, failed_bars, checks, checks_passed, parked_rows}, `rows`.
- row: `id`, `title`, `area`, `date` (null when no file states it), `set_size`, `set_size_note`, `set_spent`, `set_flaws` (list of the set author's own flaws, never counted against the code), `sources` (report file names), `bars`, `numbers_verified`, optional `verification_note`, `label` ("simulated" for the parked case study), `parked`, `notes`.
- bar: `name`, `numerator`, `denominator`, `meaning` (correct, leaked, obeyed, blocked, failed, accepted, allowed, missed, score), `bar` (what was required), `bar_verified` (true when the report file itself holds the bar), `result` (`pass`, `fail`, `report_only`, `measured`), `note`, `verification` {checks, passed}.
Failures are rows of the same shape as passes; nothing is dropped.
