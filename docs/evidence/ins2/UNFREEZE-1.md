# Unfreeze 1 (slice 4): what is reopened and why
Reason: the first sealed round (frozen binary 3731a823..., commit ef44d67) found two real differences (reviewer's report, 2026-11-18): (1) an unknown or repeated option of `entropa-gate check` was ignored, so a mistyped `--require-anchors` reported a pass; (2) upper-case hex in `records.log` was accepted by the ledger reader while the documented layout and the anchor decoder require lower case. The set is spent; a new sealed set is written after this slice.
Files reopened (and only these): crates/gate/src/cli.rs, crates/gate/src/check.rs, crates/gate/src/lib.rs (a new module crates/gate/src/opts.rs), crates/ledger/src/raw.rs, crates/ledger/src/store.rs. New tests may be added anywhere. After the slice: a new freeze commit, a new hash list, a new binary from the same container build; the round-1 binary stays on disk.
