# record_v2.json: golden vectors for the record encoding (PUBLIC TEST DATA)
Not a secret: these are the exact bytes and BLAKE3 leaf hashes of fixed, synthetic (payload, label) inputs, with no key material of any kind. Hex strings here are expected to trip secret scanners (see gitleaks notes in docs/PAXEL.md).
Provenance: generated by an independent Python script (struct packing + the `blake3` package, leaf prefix 0x00), NOT by the Rust encoder, so the test in crates/core/tests/record_encoding.rs (`golden_vectors_pin_the_exact_bytes_and_leaf_hashes`) checks the Rust code against a second implementation. Spec: docs/adr/0011-record-encoding-v2.md. Regenerate with the script recorded in docs/evidence/s0d-gen-vectors.py.
