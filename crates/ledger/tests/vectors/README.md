# ledger_event_v1.json: PUBLIC TEST DATA
Golden vectors for the explorer event encoding: fixed fields, canonical JSON (keys sorted, no whitespace, `null` for absent optional fields, `"synthetic":true`) and the BLAKE3 signing digest `BLAKE3("entropa-explorer-event-v1" 0x00 || u32be(len) || canonical)`. No keys, no signatures, nothing secret; hex strings are hashes of fixed test words. Generated by an independent Python script (docs/evidence/s7b-gen-vectors.py), not by the Rust code.
