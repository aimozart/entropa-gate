# witness_statement_v1.json: PUBLIC TEST DATA
Golden vectors for the witness statement encoding: fixed fields, canonical JSON (keys sorted, no whitespace) and the BLAKE3 signing digest `BLAKE3("entropa-witness-statement-v1" 0x00 || u32be(len) || canonical)`. No keys, no signatures, nothing secret; hex strings are hashes of fixed test words. Generated by an independent Python script (docs/evidence/s5b-gen-vectors.py), not by the Rust code, so the Rust encoder is checked against a second implementation.
