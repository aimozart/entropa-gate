Check a bundle

Pick a downloaded bundle file. It is checked inside this page: nothing is uploaded, and this page has no way to send anything anywhere.

No file checked yet.

The checker is a small WebAssembly program (@WASM_BYTES@ bytes, SHA-256 @WASM_SHA@) that only verifies. It cannot sign, has no clock, no random numbers and no network. A bundle that fails any check is refused with one of the reasons below.

  • Verified: every signature, proof and hash in the bundle checks out.
  • Refused: does not verify: the file is well formed but something in it was changed or does not match its signatures.
  • Refused: not a valid bundle: the file is not a bundle in the expected format.
  • Refused: too large: bigger than 5 MiB.
  • Refused: the checker stopped: the file could not be checked.
